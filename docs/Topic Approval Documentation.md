# Topic Approval Documentation

## Project Topic
Avorra — Interior Design Service Platform

## Brief Description
Avorra is an online platform that connects clients who need interior design services with professional designers. Clients can post their project requirements (room type, budget, style preferences) or browse designer profiles and portfolios. Designers respond with proposals including pricing and timelines. Once a designer is selected, both parties work together through the platform — sharing design files, giving feedback, requesting revisions, and completing payments — until the project is finished.

## Uniqueness of the Project
Most existing platforms either act as simple freelancer marketplaces (like Fiverr) or portfolio showcases (like Houzz). Avorra combines both into a structured, design-specific workflow. It includes milestone-based payments tied to project progress, a revision and feedback loop built into the project timeline, designer availability management, and a wishlist feature for clients to save and compare designers. All of this is tailored specifically for the interior design process rather than being a generic service marketplace.

## Your Contribution to Achieve the Uniqueness
- Designing and implementing a milestone-based payment system where funds are released to the designer only when the client approves each stage of the project
- Building a structured project workflow with defined stages (proposal → active → revision → completed) with status tracking visible to both parties
- Developing a real-time messaging and file-sharing system specifically for design collaboration (mood boards, floor plans, 3D renders)
- Creating a dual-role user system where the same person can be both a client and a designer, with separate dashboards for each role
- Implementing a designer availability and scheduling system so clients know when a designer can take on new projects
