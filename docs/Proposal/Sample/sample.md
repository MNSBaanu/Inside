

**[General Guidelines]{.underline}**

**[Introduction]{.underline}**

This must give a **brief description about the problem area**, **[the
problem]{.mark}** that you address, the importance of the problem,
**[technology]{.mark}** to solve the problem and the nature of the
**[solution]{.mark}** you propose.

(Ideally 2 -- 3 paragraphs)

Start with the Industry
Software Technology
Summary of the entire project

**[Background and Motivation]{.underline}**

Describe the background of the problem domain and **[also why you think
this problem is worth solving]{.mark}**. Try to support your reasoning
with **[references]{.mark}**. Explain why you are motivated to undertake
this project and what capabilities you have to undertake it.

(Ideally 3 - 4 paragraphs)


**[Problem in Brief]{.underline}**

What is the specific problem that you hope to solve and why is it worth
solving?

2 -- 3 paragraphs max

Reasoning with references

**[Aim]{.underline}**

Write a description such as 'The aim of this project is to develop a
system for addressing \<problem\> with the use of \<selected
technology\>'.


**[Objectives]{.underline}**

The following can be the most general objectives of any project, but you
can define more specific objectives to suit your project

-   Critical review of the \<problem domain\>

-   Critical study of technologies that can solve the problem

-   Design and develop a system for solving the problem

-   Evaluation of the proposed system

-   Preparation of final documentation

**[Proposed Solution]{.underline}**

Explain **what you are going to do**, what type of **architecture** you
will use, maybe use some high level diagrams to model your system and
explain, etc.

Simple Architectural Diagram 
Detailed Architectural Diagram

**[Resource Requirements]{.underline}**

[**Hardware and software** and other requirements(e.g. cloud
backup)]{.mark} that you will need to complete this project. Might also
want to consider about the associated **cost**.

**[Deliverables]{.underline}**

What will the final results be? Working system -- web based system,
mobile app, documentation (technical documentation, user manual) , staff
training, etc.

**[Suggested Starting Point]{.underline}**

What things / actions will you do first in order to start work on this?

e.g. Requirements gathering

**[Project Plan]{.underline}**

Give this either as a table stating the stages and the approximate
times, 
Gantt Chart


**[References]{.underline}**

Citations used directly in the preparation of this proposal. Use Harvard
style.

**[Bibliography]{.underline}**

Books and articles referred, but not cited
