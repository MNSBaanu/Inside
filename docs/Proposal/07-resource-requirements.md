## Resource Requirements

### Hardware

* Development laptop or desktop computer with a minimum of 8 GB RAM (16 GB recommended)
* Stable internet connection for cloud services and online development tools
* Android emulator and/or physical device for mobile testing; optional iOS device or Mac for iOS builds

### Software

| Category          | Software / Technology                            |
| ----------------- | ------------------------------------------------ |
| Web Frontend      | Next.js, TypeScript, Tailwind CSS                |
| Mobile Frontend   | React Native, TypeScript, Expo  |
| Backend           | Node.js, NestJS, TypeScript                      |
| Real-time         | WebSockets (NestJS Gateway) for messaging          |
| Database          | PostgreSQL                                       |
| ORM               | Prisma                                           |
| File Storage      | Cloudinary                                       |
| Payment Gateway   | Stripe                                           |
| Email             | Transactional email API (verification, notifications) |
| Hosting           | Cloud hosting (Next.js + NestJS + PostgreSQL)    |
| Development Tools | VS Code, Git, GitHub                             |
| Testing Tools     | Postman, Swagger                                 |
| Design Tools      | Figma, draw.io                                   |

### Other Requirements

* Cloud hosting for the web client, API, and PostgreSQL database
* Cloudinary account for portfolio and deliverable media
* GitHub repository for source code management, version control, and CI
* Stripe test mode for milestone payment development
* Email service account for verification and event notifications
* Expo push notification credentials for mobile alerts
* Volunteer users for system testing and evaluation (client, designer, and admin scenarios)

### Estimated Cost

Most development tools used in the project are free and open source. Cloud hosting providers, Cloudinary, and Stripe test mode can be utilized within free-tier or low-cost plans during development. Additional costs may include hosting charges and optional domain registration.
