# Introduction

Interior design today depends heavily on digital channels, yet the relationship between **clients** and **interior designers** is still often managed through disconnected steps. Finding a suitable designer, explaining what is wanted, managing revisions, and paying fairly across project stages frequently spans separate tools and informal arrangements. A client may gather visual ideas in one place, message a designer elsewhere, and settle fees outside any shared record of what was agreed or approved. A designer, in turn, needs more than a static showcase of past work—a clear brief, a structured way to deliver concepts and revisions, and payment that aligns with completed stages rather than a single upfront transfer. These gaps define the problem area this project targets: how clients and designers discover one another, communicate requirements visually, stay informed as a project moves forward, collaborate through staged delivery, and complete milestone-based payment within interior design services.

When briefing relies on text alone, style and spatial intent are easily lost, which drives mismatched expectations, repeated rework, and friction on both sides. Interior projects also carry meaningful financial commitment, so uncertainty about progress or payment undermines confidence long before the final installation. Keeping client and designer activity in one dependable process matters because it can shorten misunderstandings, keep feedback and status updates in context, make approvals visible, and tie release of funds to work the client has actually accepted—outcomes that are difficult to achieve when messages, alerts, and payments each sit on a different channel.

To meet that need, this project proposes **Inside**, a web-based platform that **connects clients and interior designers in a single environment** from first inspiration through project completion. Built with **Next.js** for the user interface and **ASP.NET Core 8** for application logic, with data held in a relational database on **AWS** cloud infrastructure and milestone payments handled through **Stripe**, the system lets clients browse completed room projects, build moodboards, receive structured briefs derived from their selections, compare designer suitability, post requests, and approve work stage by stage before funds are released. Designers publish portfolio case studies, respond with scoped proposals, upload deliverables for each project stage, and receive payment as the client confirms progress. Once a project is under way, both parties use a shared workspace to exchange messages, share feedback on deliverables, and receive notifications when a proposal arrives, a stage needs approval, or a milestone payment is completed—so communication and awareness stay tied to the project itself rather than scattered across external apps. In that way, technology supports one environment where clients and interior designers interact directly: visual preference guides hiring, staged collaboration carries the work forward, messaging and alerts keep both sides aligned, and payment reflects agreed progress rather than arrangements handled outside the platform.
