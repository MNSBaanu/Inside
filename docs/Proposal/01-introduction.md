# Introduction

The interior design industry increasingly depends on digital platforms for inspiration, designer discovery, and project coordination. However, most existing solutions address only part of this journey. Portfolio platforms such as Behance and Dribbble excel at showcasing creative work but provide no structured path to hire a designer, manage revisions, or process payments. General freelance marketplaces such as Fiverr support hiring and transactions but treat interior design like any other service category, relying heavily on text-based job posts rather than visual design compatibility. Dedicated online interior design services such as Havenly and Decorilla offer end-to-end packages but often limit how freely clients browse and select designers based on demonstrated completed work.

This fragmentation leads to unclear requirements, repeated revisions, and opaque payments when clients use separate tools for inspiration, communication, and payment.

This project proposes **Inside**, an interior design service platform that unifies portfolio-first discovery, **moodboard-driven structured briefs**, **designer–client fit scoring**, **stage-gated project workspaces**, and **transparent milestone payments** within a single AWS-hosted environment. Clients browse completed room projects, curate moodboards, receive an auto-generated brief, evaluate designers by fit score, hire through proposals, and collaborate through interior-design-specific stages. Designers publish case studies, respond to requests, and deliver work per stage with client approval gates.

The system is implemented using **Next.js** (presentation on AWS Amplify), **ASP.NET Core 8 Web API** (application tier on ECS Fargate), **Amazon RDS PostgreSQL** with Entity Framework Core, **Amazon S3**, **AWS Cognito**, **AWS SES**, and **Stripe**. Full user and system flows are documented in [SYSTEM-OVERVIEW.md](../SYSTEM-OVERVIEW.md).
