# Aim

The aim of this project is to **design, develop, and evaluate Inside**, a web-based interior design service platform that enables clients to discover designers through portfolio projects, generate **structured briefs from moodboards**, rank designers using **fit scoring**, collaborate through a **stage-gated workspace**, and complete **milestone-based payments** with a transparent ledger — using **Next.js**, **ASP.NET Core 8**, **Amazon RDS PostgreSQL**, **AWS cloud services** (Amplify, ECS, S3, CloudFront, Cognito, SES), and **Stripe**.
