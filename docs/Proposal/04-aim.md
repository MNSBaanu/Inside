# Aim

The aim of this project is to **design, develop, and evaluate Inside**, a web-based interior design service platform that enables clients to discover designers through portfolio projects, express visual preferences via moodboards, manage hiring through proposals, collaborate via a structured multi-stage project workspace, and complete milestone-based payments — using **Next.js**, **Node.js with Express**, **MongoDB Atlas**, **AWS cloud infrastructure**, **Stripe**, and related industry-standard services.
