# Aim

The aim of this project is to **design, develop, and evaluate** an Interior Design Service Platform that addresses fragmented designer discovery, project communication, and payment management by providing a centralized environment for clients and interior designers through a **web application** and a **mobile application**, with visual-led discovery, structured briefs, designer fit scoring, stage-gated collaboration, and milestone payments, using **Next.js**, **React Native**, **Node.js / NestJS**, **PostgreSQL**, **Prisma**, **Cloudinary**, cloud hosting, **GitHub**, and **Stripe** payment integration.
