# Aim

The aim of this project is to design, develop, and evaluate a web-based interior design service platform that addresses the fragmentation of client–designer commissions—from discovery and hiring through collaboration to payment—by integrating visual-led discovery, a shared project workspace, and secure payments tied to client approval, with the use of **Next.js**, **ASP.NET Core 8**, a relational database on **AWS**, and **Stripe**.
