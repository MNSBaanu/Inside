# Deliverables

## Working system

- A **web-based interior design service platform** — Next.js for clients, designers, and administrators; NestJS REST API with real-time messaging; PostgreSQL and Cloudinary; cloud-hosted.

- A **React Native mobile application** (iOS/Android) on the same API — push notifications, messaging, project progress, stage approval and rejection, milestone payment confirmation, and role switching.

- **User accounts** — registration as client or designer, login and logout, password reset, email verification, profiles and settings, dual-role switching, and role-based access (client, designer, administrator).

- **Discovery and portfolios** — designer portfolio projects, discovery feed with search and filters (style, room type, budget), profiles with availability, and saved favourite designers.

- **Moodboards, briefs, and fit scoring** — moodboards with saved inspirations, auto-generated structured briefs (editable by the client), and ranked designers with fit score breakdown.

- **Hiring and project workspace** — open and direct requests, proposals, comparison, and acceptance; stage-gated workspace (proposal, concept, design, revision, completion) with deliverables, version history, feedback, approve or reject, progress, timelines, activity history; messaging and notifications on web and mobile.

- **Payments, reviews, trust, and administration** — Stripe milestone payments with ledger and history; post-completion reviews and ratings; designer verification, reporting, and blocking; administrator tools for users, verification, moderation, projects, analytics, and portfolio content.

## Documentation

- **Project proposal** — sections 01–12, merged as a single PDF for ELMS submission.

- **Technical documentation** — system architecture, data model, API specification, brief and fit-scoring logic, messaging and notification design, and deployment notes.

- **User manual** — guides for clients, designers, and administrators on web and mobile.

- **Final report / dissertation** — project outcomes and evaluation of brief clarity, fit score usefulness, and the stage-gated workflow.

- **Test report** — results from unit, integration, end-to-end, and user acceptance testing.
