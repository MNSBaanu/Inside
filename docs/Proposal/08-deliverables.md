# Deliverables

## Working system

- A **web-based interior design service platform** — Next.js client and NestJS REST API, cloud-hosted with PostgreSQL and Cloudinary.
- A **React Native mobile application** (iOS/Android) using the same API for notifications, messaging, approvals, and payments on the go.
- **Discovery and moodboards** — portfolio feed with style, room, and budget filters; saved inspirations and structured brief generation.
- **Fit scoring module** — ranked designers with score breakdown for each moodboard.
- **Hiring flow** — open project requests or direct contact with a designer; targeted or multi-designer proposals; client comparison/selection; project created on acceptance.
- **Stage-gated project workspace** — deliverables, version history, per-stage approval, messaging, and notifications (web and mobile).
- **Milestone payment ledger** — Stripe integration with payment records tied to client approval.
- **Dual-role dashboards**, designer availability, wishlist, and post-completion reviews.

## Documentation

- **Project proposal** (sections 00–12, merged PDF for ELMS).
- **Technical documentation** — architecture, data model, API specification, brief/fit-scoring logic, deployment notes.
- **User manual** — client and designer guides (web and mobile).
- **Final report / dissertation** — including evaluation of brief clarity, fit score usefulness, and staged workflow.
- **Test report** — unit, integration, end-to-end, and user acceptance results.
